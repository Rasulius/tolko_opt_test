## Требования

- Python 3.10 и выше (проверял на 3.14).
- Для `starter.py` и тестов — только стандартная библиотека, ставить ничего не нужно.
- `pytest` опционален.

## Как запустить

Команды выполняются из папки с файлами.

1. Демо-пример из задания:
``
python starter.py
``
Ожидаемый вывод: {'price': Decimal('4728.00'), 'decision': 'APPLY', 'reason': 'Цена конкурента снижена на 1,5%'}

3. Тесты через pytest:

python -m pytest -q


3. Тесты без pytest, только стандартная библиотека:

python -m unittest -v test_recommend_price


Все тесты должны быть зелёными.

## Что покрывают тесты

- обычный расчёт на данных из примера: 4728.00, APPLY;
- Decimal вместо float, округление вниз до копейки, учёт `min_price`;
- ошибка источника, `status = partial` / `error` и таймаут → HOLD с текущей ценой;
- нет подходящих предложений → HOLD, даже если текущая цена ниже `min_price`;
- отклонение больше 30 % в обе стороны → REVIEW, ровно 30 % → APPLY;
- собственный магазин `MYSHOP` исключается без учёта регистра, доставка дольше 6 дней и `None` не учитывается.
